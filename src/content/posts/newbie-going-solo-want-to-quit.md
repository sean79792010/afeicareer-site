## 為什麼偏偏是要上線的時候最想走

很多人以為，撐過前三個月就過關了。

實際上，快上線的這段時間，常常比剛報到時更難受。

跟班的時候雖然辛苦，但學姊就在旁邊，不會的隨時可以問。上線之後，團隊還是在，只是帶你的人不一定隨時在身邊：整組病人的照護要由你主動安排，下班前的紀錄要自己寫完，病人有變化時，除了要運用自己敏銳的觀察力發現，還要能給予立即的處置。

所以這個時候想離職，不一定是你退步了。很多時候是你第一次真實感受到「要自己扛」的重量，而那個感覺讓你害怕。

先別急著下結論，把這份害怕拆開來看看。

---

## 上線前最常聽到的五種害怕

這幾年陪快上線的新人談，最常出現的是下面五種。你可能同時有好幾種，這很正常。

### 一、覺得自己還沒準備好

「學姊說我可以上線了，但我自己覺得還不行。」

這是最常見的一種。要分辨的是：你覺得沒準備好，是因為**某幾項照護真的還沒把握**，還是**整體來說就是不安心**？

兩種也可能同時存在。如果是前者，可以把那幾項列出來，對照單位的評核項目，找帶教者確認哪些已經可以、哪些還要補。如果是後者，其實很少有人在上線那天就覺得自己準備好了。那份「準備好」的感覺，多半是上線以後一次一次做過，才慢慢長出來的。

### 二、害怕獨立之後孤立無援

「以前有學姊在旁邊，上線之後遇到不會的，我要找誰？」

這種害怕，擔心的其實是**支援**。上線以後還是有人可以問，差別在你要知道問誰、怎麼問。

上線前可以先確認：每一班可以找的負責人是誰、對方在忙的時候下一個可以找誰、醫師怎麼聯絡。遇到緊急狀況，就依院內流程直接啟動支援，不必等某位學姊回覆。心裡有一張「我可以找誰」的名單，孤單的感覺會小很多。

比如：

| 遇到的問題 | 可以找誰 |
|---|---|
| 醫囑有疑問 | 醫師或 NP |
| 藥物交互作用 | 藥師 |
| 電腦系統問題 | 資訊室 |
| 空調、負壓隔離病室壓力異常 | 工務室 |
| 照護上拿不定主意 | 當班負責人、組長或資深學姊 |
| 病人緊急狀況 | 依院內流程直接啟動支援 |

### 三、害怕自己動作慢，拖累學姊或延遲下班

「我做不完的話，學姊要幫我收，大家都要晚下班。」

新人很在意自己會不會變成別人的負擔。這份在意是好的，但它不該讓你把該問的吞下去、把該核對的省掉。

上線初期慢是很常見的。你能做的，是發現做不完的時候**早一點講**：跟當班負責人說明還剩哪些事、哪些有時效，請對方幫你排先後、看怎麼分工。撐到交班前才說，別人就很難幫上忙了。

至於慢本身怎麼看、怎麼一步一步變穩，我在〈[動作慢就是不好的新人嗎？](/posts/slow-newbie-three-things/)〉寫得比較完整。

### 四、害怕病人出事，自己無法處理

「如果病人突然惡化，只有我在，我處理不來怎麼辦？」

會這樣怕，通常是因為你把病人放在很重的位置。

先說一件事：**病人狀況變化的時候，你不是一個人處理。** 你要做的是及早發現、評估，依院內流程求援、通知醫師，放上生理監測器持續觀察，並做你受過訓練、符合規範的處置；如果病人已經沒有呼吸心跳，就立即開始急救，不要只等支援到場。接下來，由團隊依病況和醫囑一起處理。你不需要在上線第一天就會處理所有狀況，你需要的是**知道什麼時候該叫人，而且敢叫**。

說不出原因、只是覺得不太對勁，也是可以叫人的理由。

### 五、覺得自己不適合臨床

「我好像就是不適合。」

這句話我聽過很多次，而它常常是前面四種害怕累積起來之後的結論。

所以在你把「不適合」當成答案之前，可以先回頭看看：讓你這麼想的，是不是其實是前面那幾種害怕？如果是，它們大多有具體的做法可以處理。

但也有一種情況是真的：你發現自己在意的東西，跟目前這份工作對不上。例如你很需要穩定的作息，而現在的單位就是要輪班。這跟努力無關，是你的需求和這份工作的型態不同。可以先問問看有沒有調整班別或院內轉調的可能，再用下面三個問題來評估。

## 緊張到睡不著，要注意什麼

上線前緊張、焦慮不安很常見。有些人會開始睡不好，前一晚一直想著明天的病人，躺了很久還醒著。

單憑這些反應，並不能說明你適不適合護理。更需要留意的，是它有沒有持續、變嚴重，或已經影響到生活和照護安全。

下面這些是值得找人幫忙的訊號：

- 睡不好、焦慮的狀況一直沒有變好，甚至愈來愈嚴重
- 上班的時候沒辦法專心，開始出現平常不會犯的疏失
- 一想到要上班，就心悸、胃痛、想哭
- 休假的日子也一直被上班的事佔滿，完全沒辦法放鬆

出現這些狀況，不必等撐很久，就可以找身心科或心理諮商談談；身體的不舒服也可以視情況就醫。也可以問問人資或員工健康服務窗口，院內有沒有員工諮詢或心理支持的資源，而院外的心理諮商也是選擇。

如果上班時已經擔心自己沒辦法安全照顧病人，請當下就跟當班負責人說，這是保護病人，也是保護你。

> ☎️ 如果出現傷害自己或不想活的念頭，請馬上告訴一個你信任的人，也可以撥 **1925 安心專線**（24 小時）；如果有立即的危險，請直接撥 119 或到急診。

這些都是在照顧自己，跟你能不能當護理師是兩件事。

## 要留還是要走，先回答三個問題

在諮詢裡，我陪新人評估要留還是要走，通常會從這三個問題開始。你可以拿一張紙，一題一題寫下來。

### 問題一：你想留、想走的原因，各是什麼？

不要只寫想走的原因，想留的也要寫。

很多人寫完才發現，想留的理由其實不少，例如單位裡有幾個人對你很好，或是捨不得已經學會的東西。想走的理由裡，則常常混著前面那幾種害怕。

兩邊都寫出來，你才看得到自己真正在拉扯的是什麼。

### 問題二：你期望的理想職場，有哪些特徵？

試著寫出你最在意的幾件事，例如：

- 團隊是不是會互相幫忙
- 單位的文化、氣氛
- 薪資與福利
- 班別與作息
- 有沒有人願意教、有沒有學習的空間

寫完之後排個順序，最在意的放最前面。然後對照現在的單位：你最在意的那幾項，這裡有嗎？

如果前幾項這裡大致都有，只是你還在害怕，而身心也還撐得住，那值得再給自己一段時間。如果前幾項這裡怎麼樣都給不了，那就是一個比較清楚的訊號。

### 問題三：目前的困難，有辦法透過求助來克服嗎？

把讓你想走的困難一個一個列出來，先看看哪些是「不熟悉」造成的。

像是放置留置針、抽血這類技術，電腦的操作介面，或是檢查前的準備流程，這些多半可以靠多做、熟能生巧慢慢改善。如果你卡住的是這一類，而且你自己也能接受這段練習的過程，可以試著再多嘗試一下。

接著，在其他困難旁邊問自己：這件事，如果找人幫忙，有機會變好嗎？

- 還沒把握的照護 → 可以找帶教者補，**可以求助**
- 不知道上線後可以問誰 → 可以先跟組長確認，**可以求助**
- 需要的示範或回饋還不夠明確 → 記下具體情境，找帶教者或護理長一起看怎麼補強，**看單位回應**
- 輪班讓身體撐不住、家裡需要你固定時間在 → 可以先問調班別或轉調的可能，但這跟目前單位的班型有關，**很難只靠求助解決**

舉一個最常見的例子：**針打不上。**

打了一針沒進，先跟病人說：

> 「不好意思，讓您痛了一下。這條血管跟我評估的不太一樣，我請學姊來幫您打，不會讓您反覆被扎。」

找學姊的時候，把狀況講清楚：

> 「學姊，8 床要打留置針，我剛剛在左手前臂扎了一次沒有成功，血管比較細、容易滑。可以請你幫忙打嗎？我在旁邊一起看。」

學姊來打的時候，在旁邊看她怎麼選血管、怎麼進針，事後再問她是怎麼判斷的。扎幾次要換手、家屬要求換資深的人來打可以怎麼回，前一篇〈[陪你穿越調適期](/posts/clinical-newbie-adjustment/)〉的 Q5 有寫。

還有一種困難，是單位的文化、風氣跟你合不來。這就要看你自己想不想融入。如果你很在意歸屬感，而現在的單位給不了，你可以選擇做自己，也可以選擇換一個單位。這沒有對錯，只看你自己想怎麼選。

如果遇到的是羞辱、威脅，或反映後還是得不到必要的協助，可以依院內管道向督導、教學負責人或申訴窗口反映。那不是你不夠努力。

把上面這些整理成一張表，你可以對照看看自己的困難屬於哪一種：

| 困難的類型 | 例子 | 可以怎麼做 |
|---|---|---|
| 靠多做能改善 | 放置留置針、抽血、電腦操作介面、檢查準備流程 | 自己也能接受練習的過程，就再多嘗試一下 |
| 找人幫忙能改善 | 還沒把握的照護、不知道上線後問誰、針打不上 | 把狀況講清楚，請帶教者、組長或學姊幫忙 |
| 要看單位回應 | 需要的示範或回饋不夠明確 | 記下具體情境，找帶教者或護理長談 |
| 很難只靠求助解決 | 輪班讓身體撐不住、家裡需要你固定時間在 | 先問調班別或轉調的可能，再評估其他工作型態 |
| 看你自己的選擇 | 單位的文化、風氣合不來 | 想融入就留下，很在意歸屬感也可以換單位，沒有對錯 |

可以求助的困難，就先試著求助，約好一段觀察期再做決定。很難靠求助解決的困難，或是已經影響到健康和照護安全的，就不必因為其他條件不錯而勉強自己留下。

## 上線前，你還可以做的事

如果你看完上面，覺得還想再試試，這幾件事現在就可以做：

**列一張「還沒把握」的清單。** 具體到某一類病人或某一項技術，旁邊寫上你卡在哪一步、需要什麼協助。清單寫出來，模糊的恐懼就會變成幾件可以練的事。

**帶著清單找帶教者或護理長談。** 講你已經比較有把握的、還沒把握的，以及你希望怎麼補。例如某類病人再跟幾次、上線初期能不能先從病情較穩定的病人開始、上線後有誰可以讓你問。實際怎麼安排要看單位的訓練制度和人力，但講得愈具體，愈好一起評估。

**找幾個可以說話的人。** 臨床上的問題，找當班負責人或資深的學姊；心裡的壓力，也可以找比你早一兩年來的學姊或同期的夥伴聊聊。上線以後，知道有人可以問、有人可以說，會安心很多。

**約一個回顧的時間。** 例如上線後一個月，再回頭看看那張清單：哪些已經不太需要別人提醒、遇到異常時知不知道第一步、什麼時候該找人。很多人會發現，當初最怕的那幾項，已經穩了不少。

## 如果最後決定離開

也有人評估完之後，還是決定離開。

那三個月沒有白費。你知道了自己在壓力下會怎麼反應，也更知道自己在意什麼，這些都會帶到下一份工作裡。

如果你還想留在護理，只是不想留在臨床，可以先看看〈[護理師轉職地圖](/posts/nursing-normal-shift-career-map/)〉，了解其他工作實際的內容、班別和需要的條件，再選一條你走得下去的路。

## 最後想跟你說的話

快上線的時候想離職，是很多新人都走過的一段，跟你夠不夠好沒有關係。

要留還是要走，你不需要一個人決定。可以找帶教者、護理長，或是走過這段的人聊聊。

先照顧好自己，再決定下一步。
